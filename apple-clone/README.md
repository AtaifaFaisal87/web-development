# Apple Website Clone

This is a practice project I made while learning web development. I wanted to try recreating the look and feel of the Apple website to get better at HTML and CSS, and to try out a bit of JavaScript along the way.

This is **not affiliated with Apple** in any way — it's just a clone made for learning purposes.

## Features

* Apple-style navigation bar
* Hero section with an autoplay video
* iPhone product section
* Apple Watch sections
* AirPods, iCloud+, and MacBook sections
* Product cards laid out using CSS Grid
* Apple-style footnotes
* Footer with Apple-style navigation links
* A small clone notice at the bottom of the page

## Built With

* HTML
* CSS
* JavaScript

## What I Practiced

* Structuring a multi-section webpage with HTML
* Styling with CSS, including layouts using CSS Grid
* Making the navbar and sections look close to the real Apple website
* Adding a bit of interactivity with JavaScript
* Getting more comfortable organizing a bigger project instead of just small snippets
